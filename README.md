# Router Boss
Native Android app (Kotlin + Jetpack Compose) for TP-Link routers: live speed (SNMP), who is on my wifi, priority/QoS helper, router settings inside the app.

## Get the APK (free, no Android Studio)
1. Unzip this file on a computer.
2. Create a GitHub repository, then upload EVERYTHING from the unzipped folder (drag the files and folders in, including the hidden .github folder).
   If .github did not upload: Add file > Create new file, name it `.github/workflows/build.yml`, and paste the contents of `build.yml` from this zip.
3. Open the Actions tab > Build APK > Run workflow. Wait about 5 minutes.
4. Open the finished run, download RouterBoss-apk, unzip, install app-debug.apk on your phone.

## Or with Android Studio
File > Open this folder, wait for sync, press Run.
